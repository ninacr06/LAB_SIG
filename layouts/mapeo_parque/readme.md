# Disposición: Mapeo de parque comunal

Curso SIG – Trabajo de campo OSM. Cada botón crea un waypoint con ese nombre.

| Botón | Etiqueta OSM | Geometría | Cómo capturarlo |
|---|---|---|---|
| BANCA | amenity=bench | Punto | Un waypoint sobre la banca |
| BASURERO | amenity=waste_basket | Punto | Un waypoint |
| POSTE DE LUZ | highway=street_lamp | Punto | Un waypoint |
| ÁRBOL | natural=tree | Punto | Un waypoint |
| CÁMARA | man_made=surveillance | Punto | Un waypoint |
| HILERA ÁRBOLES | natural=tree_row | Línea | Un waypoint al inicio y otro al final (y en curvas) |
| SENDERO | highway=footway | Línea | Un waypoint al inicio, curvas y final |
| CANCHA | leisure=pitch + sport=basketball;soccer | Polígono | Un waypoint en cada esquina |
| SKATE PARK | leisure=pitch + sport=skateboard | Polígono | Un waypoint en cada esquina |
| PARQUE INFANTIL | leisure=playground | Polígono | Un waypoint en cada esquina |

Usar siempre el botón de FOTO justo después para dejar evidencia.
